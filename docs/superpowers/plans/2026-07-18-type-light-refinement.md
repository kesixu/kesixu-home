# 字体一致性与光影精修计划

- 目标：让 360–430px 手机竖屏使用同一套固定字号与行距，并确保自托管字体在慢速手机上最终一致加载。
- 文件：调整 `site/style.css` 的字体标尺、字体加载策略、背景层次、项目卡受光与星图/余烬细节；按需细化 `site/main.js` 的火花体积光。
- 验证：新增跨尺寸字体度量断言，复跑现有 5 档动效、路径、无 JS、减弱动画与零第三方请求测试。
- 风险：光影滤镜可能增加移动 GPU 压力；以静态渐变和伪元素为主，限制 Canvas 粒子数量，不新增依赖或外部资源。
- 发布：本地截图审阅与性能检查通过后提交、推送，备份 `/var/www/kesixu-home` 再部署并从公网复测。
