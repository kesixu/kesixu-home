为什么"可信"

大多数医疗 AI 演示的是"什么都能答"。PathBot 花了最多的功夫做相反的事：在不该答的时候，把"不知道"说清楚。信任引擎独立于大模型之外，是一层看得见代码、跑得了测试、可以被审计的机制，而不是提示词里的一句客套。

三道闸，一条链

闸 一 · 执行之前

先验片，再作答

切片一进来先过分诊闸门：文件是否完整、组织覆盖率够不够、染色与组织类型是否在能力范围内。三种裁定——通过 / 谨慎 / 拒绝。超出能力边界的片子，它直接说"这张我不该看"。

闸 二 · 执行之中

过程可审计的四态判决

每一步工具调用都对照临床指南流程图核验（流程符合度 β），再用反事实探针检查模型是否真的忠于证据（证据忠实度 κ）——不信模型的自我报告，只看它的行为。最终给出四态判决：确信 / 异常标记 / 不确定 / 升级人工。

闸 三 · 证据本身

循证溯源，缺引用不加载

诊断推理依赖的每一条似然比证据，都带着 PubMed / PMC 原文引用，点开可查；知识库加载器遇到缺引用的条目会直接拒绝启动。证据库目前覆盖乳腺与结直肠两个领域最深，以"开放种子"形式持续扩充，欢迎病理专家参与复核。

一次"交白卷"的成绩

在一次域外盲测中，面对 20 例超出训练分布的病例，PathBot 的信任引擎把 20 例全部判为"不确定"——尽管底层模型硬答也能对九成。它选择了宁可承认不确定，也不装出自信。
对医疗 AI 而言，我们认为这比一个漂亮的准确率更重要。

能力面

  • 全切片影像（WSI）原生支持——基于华威大学 TIA Centre 的 TIAtoolbox：.svs / .ndpi / .mrxs / .tiff / .dcm 等主流格式，深度缩放阅片。
  • 真模型，不是贴图——细胞核检测·分割·分类（HoVerNet 系 / KongNet）、组织分类与分割、H&E 直接预测基因突变线索（MSI / BRAF / TP53）等病理专用预训练模型。
  • 临床阈值哨兵——PD-L1 TPS、Ki-67、HER2、Allred 等真实决策阈值的边界预警。如实说明：计数目前由使用者提供，AI 负责核对阈值与边界风险，不是"自动读片打分"。
  • 报告可导出——Markdown / PDF 报告自动附带完整审计信息与免责声明。
  • 支持本地私有化部署——默认本地模型模式下，数据不出机器；亦可按需接入云端模型（此时数据会离开本机，页面如实相告）。

  • 这是研究预览，不是获批医疗器械；一切结果须由执业病理医生复核。
